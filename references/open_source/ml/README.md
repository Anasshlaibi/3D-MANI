# Classical ML & Optimization Intake (`/references/open_source/ml`)

## Priority Repositories Audited

### 1. scikit-learn
- **Repository:** https://github.com/scikit-learn/scikit-learn
- **License:** BSD-3-Clause
- **Classification:** Core Dependency for Tabular Process Telemetry
- **Role:** HistGradientBoosting, RandomForest, Ridge Regression, IsolationForest for anomaly detection and drift monitoring.

### 2. XGBoost
- **Repository:** https://github.com/dmlc/xgboost
- **License:** Apache-2.0
- **Classification:** Production Tabular Regressor & Defect Classifier
- **Role:** Primary gradient boosted tree algorithm for predicting actual physical warpage and tooling rework rates.

### 3. Optuna
- **Repository:** https://github.com/optuna/optuna
- **License:** MIT
- **Classification:** Core Dependency for Hyperparameter & Pareto Design Search
- **Role:** NSGA-II multi-objective optimization across constrained parameter search spaces (mass, cycle time, structural safety factor).
